# Renewly

Renewly — офлайн-трекер платных подписок: стриминг, софт, облако, спортзал и т. п. Приложение показывает, сколько вы тратите в месяц и в год, когда ближайшие списания, и заранее о них напоминает.

- Swift и SwiftUI, только фреймворки Apple: SwiftData, Swift Charts, UserNotifications. Сторонних пакетов нет.
- iPhone, iOS 17 и новее, портретная и альбомная ориентации.
- Полностью офлайн: никаких сетевых запросов и аналитики, данные хранятся только на устройстве.
- Интерфейс на русском и английском, язык выбирается по системе.

---

## 1. Что нужно

1. **Mac с Xcode 16 или новее.** Xcode бесплатно ставится из Mac App Store. Проект сохранён в формате Xcode 16, более старые версии его не откроют.
2. **iPhone с iOS 17 или новее** и кабель.
3. **Apple ID.** Чтобы поставить приложение на свой iPhone, хватит бесплатного Apple ID, но тогда его нужно переустанавливать раз в 7 дней. С платным аккаунтом Apple Developer Program ($99 в год) приложение работает год.

## 2. Как открыть проект

1. Скачайте репозиторий: на GitHub нажмите **Code → Download ZIP** и распакуйте архив (или сделайте `git clone`).
2. Дважды щёлкните файл **`Renewly.xcodeproj`** в корне папки. Откроется Xcode. Больше ничего устанавливать не нужно.

## 3. Team ID и Bundle ID (единственная ручная правка)

Все настройки подписи собраны в одном файле **`Config/Signing.xcconfig`**. Откройте его в Xcode (слева: `Config → Signing.xcconfig`) или в любом текстовом редакторе:

```
PRODUCT_BUNDLE_IDENTIFIER = com.example.renewly
DEVELOPMENT_TEAM = XXXXXXXXXX
CODE_SIGN_STYLE = Automatic
```

Поменяйте только первые две строки:

- **`PRODUCT_BUNDLE_IDENTIFIER`** — ваш уникальный идентификатор, например `com.ivanov.renewly`. Допустимы латиница, цифры, точки и дефисы.
- **`DEVELOPMENT_TEAM`** — ваш Team ID из 10 символов.
  - Сначала добавьте Apple ID в Xcode: **Xcode → Settings… → Accounts → «+» → Apple ID**.
  - **Платный аккаунт:** Team ID указан на <https://developer.apple.com/account> в разделе **Membership details**.
  - **Бесплатный Apple ID (Personal Team):** выберите в Xcode слева проект **Renewly**, затем таргет **Renewly** и вкладку **Signing & Capabilities**. В поле **Team** выберите «Ваше имя (Personal Team)». Затем на вкладке **Build Settings** найдите **Development Team**: там виден Team ID. Скопируйте его в `Signing.xcconfig`. После этого в **Build Settings** выделите строку **Development Team** на уровне таргета и нажмите Delete, чтобы значение снова бралось из xcconfig.

Сохраните файл. Больше ничего менять не нужно.

## 4. Запуск на iPhone

1. Подключите iPhone к Mac кабелем и разблокируйте его. Если телефон спросит **«Доверять этому компьютеру?»**, нажмите **Доверять**.
2. **Включите режим разработчика:** на iPhone откройте **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включите его и перезагрузите телефон, когда он предложит. Если такого пункта нет, один раз запустите приложение из Xcode (шаг 4), и пункт появится.
3. В Xcode вверху выберите схему **Renewly**, а рядом с ней свой iPhone в списке устройств.
4. Нажмите **Run** (▶) или **⌘R**. Xcode соберёт приложение, установит его и запустит.
5. Если iOS покажет **«Ненадёжный разработчик»**, откройте **Настройки → Основные → VPN и управление устройством**, выберите свой профиль разработчика (ваш Apple ID) и нажмите **Доверять**. Затем снова откройте Renewly.

### Типовые ошибки подписи

| Сообщение в Xcode | Что делать |
|---|---|
| *Failed to register bundle identifier* / *The app identifier “com.example.renewly” cannot be registered to your development team* | Этот Bundle ID уже занят. Впишите в `PRODUCT_BUNDLE_IDENTIFIER` другой уникальный идентификатор, например `com.ivanov.renewly2`. |
| *Signing for “Renewly” requires a development team* / *No Account for Team “XXXXXXXXXX”* | Team ID не указан или указан неверно. Добавьте Apple ID в **Xcode → Settings → Accounts** и впишите правильный `DEVELOPMENT_TEAM`. |
| *Device “…” isn’t registered in your developer account* / *No profiles for “…” were found* | Убедитесь, что iPhone подключён и выбран как устройство запуска. При `CODE_SIGN_STYLE = Automatic` Xcode регистрирует устройство сам: нажмите **Try Again** на вкладке **Signing & Capabilities**. С бесплатным Apple ID можно зарегистрировать не больше 3 устройств. |
| *Developer Mode disabled* | Включите режим разработчика (шаг 4.2) и перезагрузите iPhone. |
| *Could not launch “Renewly” … untrusted developer* | Доверьтесь профилю в **Настройки → Основные → VPN и управление устройством** (шаг 4.5). |
| *The maximum number of apps for free development profiles has been reached* | С бесплатным Apple ID одновременно можно держать не больше 3 своих приложений. Удалите одно из них с iPhone. |

## 5. Сборка и тесты из командной строки

Команды выполняются на Mac с Xcode 16+ из корня репозитория. Подпись для них не нужна.

Сборка под симулятор:

```bash
xcodebuild build -project Renewly.xcodeproj -scheme Renewly \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO
```

Сборка под устройство без подписи (проверка, что код компилируется для iPhone):

```bash
xcodebuild build -project Renewly.xcodeproj -scheme Renewly \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO
```

Запуск unit-тестов. Сначала посмотрите список симуляторов и подставьте в команду имя любого iPhone из него:

```bash
xcrun simctl list devices available | grep iPhone
xcodebuild test -project Renewly.xcodeproj -scheme Renewly \
  -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO
```

В Xcode тесты запускаются через **Product → Test** (**⌘U**).

GitHub Actions (`.github/workflows/ios.yml`) запускается на каждый push и pull request. Он собирает приложение без подписи под устройство и под симулятор, затем прогоняет тесты. Самый новый доступный симулятор iPhone выбирается автоматически.

## 6. Как пользоваться приложением

Внизу четыре вкладки: **Обзор**, **Подписки**, **Статистика**, **Настройки**.

- **Демо-данные.** На пустом экране «Обзор» или в **Настройки → Загрузить демо-данные** нажмите **«Загрузить демо-данные»**. Появятся 12 примеров подписок в разных валютах, с разными периодами и статусами: пробный период, пауза, отмена, списания 31-го числа и 29 февраля. Для валют, у которых курс ещё не задан, подставятся примерные курсы. При повторной загрузке дубликаты не появляются.
- **Добавление подписки.** Нажмите **+**. Название и сумма обязательны, сумма должна быть больше 0 и вводится через запятую или точку. Дальше выберите валюту и период оплаты: неделя, месяц, квартал, год или свой («каждые N дней/недель/месяцев/лет»). Укажите дату первого платежа, категорию, при необходимости дату окончания пробного периода, напоминание и заметку. Ошибки показываются под полями, а кнопка «Сохранить» неактивна, пока данные неверны.
- **Обзор.** Расходы в месяц и в год в базовой валюте, расходы по категориям и списания на ближайшие 30 дней.
- **Подписки.**
  - Поиск по названию.
  - Фильтры по статусу, категории и периоду, сортировка (кнопка фильтра слева вверху).
  - Свайп вправо ставит подписку на паузу или возобновляет её. Свайп влево открывает «Изменить» и «Удалить».
  - Нажатие на подписку открывает карточку: следующее списание, стоимость в месяц и в год, 6 ближайших списаний, сколько потрачено всего, а также действия: пауза, возобновление, отмена с датой, изменение и удаление.
- **Статистика.** Прогноз расходов по месяцам на 3, 6 или 12 месяцев: строится по реальным датам списаний, столбцы разбиты по категориям. Ниже доли категорий и топ-5 самых дорогих подписок.
- **Настройки.**
  - Базовая валюта.
  - Курсы валют в виде «1 USD = … RUB». Подписка без курса считается по курсу 1 и помечается «Курс не задан».
  - Время напоминаний (по умолчанию 09:00), статус разрешения на уведомления и кнопка перехода в системные настройки, если уведомления запрещены.
  - Экспорт в JSON и CSV через «Поделиться», импорт из JSON, ранее экспортированного Renewly.
  - Удаление всех данных.

### Как считаются списания

- Списания всегда отсчитываются от даты первого платежа. Если в месяце нет такого числа, берётся последний день месяца. Пример: подписка от 31 января списывается 28 (или 29) февраля, 31 марта, 30 апреля, 31 мая. То же правило действует для кварталов, лет (29 февраля) и периода «каждые N месяцев».
- При пробном периоде до его окончания списаний нет. Первое списание приходится на дату окончания, дальше цикл идёт от неё.
- Подписка на паузе не входит в суммы, прогноз и напоминания. Отменённая подписка учитывается до даты отмены, после неё — нет.
- Стоимость в месяц: неделя × 52 / 12, квартал / 3, год / 12, день × 365 / 12. Для периода «каждые N» результат делится на N.
- Планируется не больше 64 ближайших напоминаний (лимит iOS). Они пересоздаются при каждом изменении данных и при открытии приложения.

## Структура проекта

```
Renewly.xcodeproj/        проект Xcode (открывается сразу, общая схема «Renewly»)
Config/Signing.xcconfig   Bundle ID, Team ID, стиль подписи; единственный файл для правки
Renewly/
  Models/                 модели SwiftData и value-типы (снимок подписки, черновик формы, перечисления)
  Services/               чистая логика (даты списаний, стоимость, прогноз, напоминания, импорт и экспорт),
                          сервис уведомлений и слой сохранения
  Views/                  экраны SwiftUI, сгруппированные по функциям
  Resources/              каталог ресурсов, String Catalog (русский и английский)
RenewlyTests/             unit-тесты XCTest
.github/workflows/ios.yml CI: сборка без подписи и тесты на симуляторе
REPORT.md                 отчёт о реализации
```
